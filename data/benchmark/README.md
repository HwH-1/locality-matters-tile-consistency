# AbstraBench — a licence-clean image set for abstraction-filter evaluation

Status: **building**. Current contents: 145 images (Metropolitan Museum of Art, Open
Access, CC0), one manifest row per image with per-object licence evidence and a
SHA-1 hash. Target size for the paper: ≥ 200 real-world images plus controlled
synthetic strata.

## Why this benchmark exists

Tile-consistency claims are statements about *what the filter computes*, so the
evaluation set must be free of two confounds: (1) licence risk (an author cannot
re-run a comparison whose images cannot be redistributed), and (2) unknown
provenance (a measured difference cannot be traced back to a specific file). Every
image here therefore ships with its source identifier, its landing page, the exact
API field that established public-domain status, and a content hash.

## Sources and how they were acquired

| stratum | source | acquisition | licence basis | count |
|---|---|---|---|---|
| `met` | The Metropolitan Museum of Art Open Access API (`collectionapi.metmuseum.org`) | official JSON API, HTTP GET, no crawling, no login, no robots exclusion issues | `isPublicDomain == true` recorded per object in `license_evidence`; Met Open Access programme releases these works under CC0 | 145 |
| `synthetic` | generated by `scripts/build_benchmark.py` | programmatic | our own output, released under the same terms as the code | planned |
| `skimage` | scikit-image bundled sample data | in-process API | see `scripts/build_benchmark.py` header for the per-file licence notes | planned |

No web scraping was used for any image in this repository. The acquisition route was
chosen from official public-domain APIs first; crawling was never needed and therefore
never attempted.

## Selection rule (documented so it can be audited for cherry-picking)

1. Query the Met API by department (`departments` → `objects?departmentIds=`).
2. Keep an object only if `isPublicDomain` is true and a `primaryImage` URL exists.
3. Require the original image's longest side ≥ 768 px, so that a 384 px or 512 px
   evaluation crop is a downscale rather than an upscale.
4. Download the JPEG as served by the museum's own CDN (`images.metmuseum.org`).
5. Record `source_id`, `page_url`, `image_url`, `title`, `medium`, `object_date`,
   `rightsAndReproduction`, `license`, `license_evidence`, `attribution`, original and
   stored dimensions, byte size and SHA-1.

Images are stored at longest side ≤ 1024 px. Minimum observed short side: 448 px;
median short side: 803 px. Total volume ≈ 30 MB for 145 images.

Observed texture strata (from `medium`): oil on canvas 63, oil on wood 29, tempera on
wood 12, oil and gold on oak panel 7, vellum laid on card 4, ivory 4, oil on paper 2,
oil on oak 2, plus decorative-object surfaces (carved/gilded wood, metalwork). Object
dates span the 17th–19th centuries. All 145 SHA-1 hashes are distinct (verified).

## Manifest schema (`manifest_met.csv`)

`id, file, source, source_id, page_url, image_url, title, medium, department,
object_date, license, license_evidence, attribution, orig_width, orig_height, width,
height, bytes, sha1`

Note: `department` is currently empty because the Met listing endpoint does not
return `departmentTitle`; the department is implicit in the query that produced the
row. Filling it requires one extra detail-request per object and is deliberately not
a blocker.

## Attribution and reuse

CC0 waives copyright, so no attribution is legally required. We still record an
`attribution` string per object because it is good practice and because it lets a
reader identify the exact work: e.g. "The Metropolitan Museum of Art, CC0 (Gift of
J. Pierpont Morgan, 1906)".

You may redistribute this set with a paper. Please redistribute the manifest with it —
the licence evidence is part of the deliverable.

## Known limitations

- Predominantly pre-1900 easel paintings and decorative arts. Good texture diversity,
  but no photographs, no text-heavy images, no medical/remote-sensing imagery. Strata
  for those are planned; conclusions in the paper are scoped accordingly.
- Downscaling to 384 px removes some fine detail; the paper's main sweep therefore uses
  384 px for statistical throughput and reports the large-canvas results separately.
